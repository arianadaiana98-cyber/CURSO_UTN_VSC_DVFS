Pasos para crear un repositorio

    git init
            Crea un repositorio de git en el proyecto donde se ejecuta

    git add 
            Añade los archivos sin seguimiento al repositorio de git 
    
    git commit -m 'Mensaje Descriptivo'
            Versionar los cambios añadidos

    COMANDOS GIT:

    git branch -M main 
        Renombrar la rama principal

    
    git status 
                Da un status del repositorio

        git remote add origin https://github.com/arianadaiana98-cyber/CURSO_UTN_VSC_DVFS.git
        Añadir una dirección remota (dirección de repositorio remoto) a nuestro repo local.

        git remote -v 
        Ves a donde esta conectado tu repo local

        git remote set-url origin <dirección del repo> 
        Cambia la url a la que está conectada el repo local      

        git push -u origin main 
        Sube los cambios a la nube

        Para actualizar el repo y subir otro commmit ejecutar:

        Git add .
        Git commit -m 'nombre'
